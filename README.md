# Codeforces

Gym folder contains solutions to Codeforces Gym problems.
Gym problems are identified by a numeric contest ID followed by the problem letter.

ProblemSet folder contains solutions from the main Codeforces Problemset as well as acmsguru.
If the filename contains a problem letter, it is a Codeforces Main problem.
If the filename does not contain a problem letter, it is an acmsguru problem.
